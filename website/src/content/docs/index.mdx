import { Card, CardGrid, LinkCard } from '@astrojs/starlight/components';

```yaml
# .github/workflows/resume.yml in your private CV repo
jobs:
  build:
    uses: EndLess728/resume-builder/.github/workflows/build-resume.yml@v1
    with:
      cv_file: My_CV.yaml
    secrets: inherit
```

Your CV lives in your own **private** repo, which calls this reusable workflow. Logs, artifacts and generated PDFs all stay there, while the pipeline code lives in one public place. Built on [RenderCV](https://github.com/rendercv/rendercv).

## What you get

<CardGrid>
  <Card title="YAML to PDF" icon="document">
    RenderCV renders your YAML to a typeset PDF and PNG previews on every push, saves them as an artifact and commits them back to your repo.
  </Card>
  <Card title="One permanent link" icon="external">
    The Google Drive module updates the same file in place, so the link on your portfolio or LinkedIn never changes.
  </Card>
  <Card title="Telegram pings" icon="comment">
    Get a message when the resume is rebuilt, optionally with the PDF attached, and another if a build fails.
  </Card>
  <Card title="Live npm stats" icon="npm">
    Entries that link to an npm package get a fresh download count, refreshed by a weekly scheduled build.
  </Card>
  <Card title="Private by design" icon="seti:lock">
    Your phone number and email never touch a public repo. Everything runs in yours.
  </Card>
  <Card title="Pinned and versioned" icon="approve-check">
    Pin `@v1` for compatible updates. Modules always load from the same commit as the workflow you pinned.
  </Card>
</CardGrid>
